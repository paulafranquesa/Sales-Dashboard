# Sales Dashboard

## Overview

This project is an interactive **Power BI Sales Dashboard** designed to analyze sales performance across different cities, products, customers, and time periods.

The dashboard combines geographic and sales analysis to provide a clear overview of business performance and identify the main factors contributing to sales.

---

## Project Objectives

The main objectives of this project are:

- Analyze total sales and sales trends over time.
- Identify the cities with the highest sales.
- Compare sales performance across different products.
- Analyze sales by customer and transportation company.
- Visualize sales geographically.
- Identify top-performing locations and products.

---

## Dashboard

The dashboard provides several perspectives for analyzing sales performance.

### Sales Overview

Key indicators include:

- Maximum sales
- Total sales
- Minimum sales

### Geographic Analysis

The map visualizes sales by location, allowing users to identify areas with higher sales activity.

### Product Analysis

Sales and quantities are analyzed across different products, including:

- Megaphones
- Balloons
- Caps

### Customer & Transportation Analysis

The dashboard also provides insights into:

- Sales by customer
- Orders by transportation company
- Sales distribution by product

### Time Analysis

The line chart shows sales evolution by quarter and product, making it possible to identify changes in sales performance over time.

---

## Key Questions

The dashboard was designed to answer questions such as:

- Which cities generate the highest sales?
- Which products sell the most?
- How do sales change over time?
- Which customers generate the most sales?
- Which transportation companies handle the most orders?
- Where are sales geographically concentrated?
